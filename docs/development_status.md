# Development status

## Current state

This repository is a **legacy placeholder release**.

The shell scripts included here are the original workflow components. They are scientifically useful as a record of the process and expected file flow, but they are not intended to represent the long-term maintained software base.

## Planned direction

The preferred long-term direction is a Python implementation that will:

- reduce dependence on brittle text parsing,
- make file handling more explicit,
- support clearer logging and error reporting,
- allow modular testing,
- better support future extensions.

## What this release should communicate

This release should communicate continuity, transparency, and traceability:

- **continuity**, because the workflow used in the paper is preserved;
- **transparency**, because the historical code is available;
- **traceability**, because users can see how files move through the pipeline.

## What it should not imply

This release should not imply that:

- the shell scripts are the final supported implementation,
- the software is feature-complete,
- the package has been fully hardened for broad deployment.
