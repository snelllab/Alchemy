# Contributing

Thank you for your interest in Alchemy.

At this stage, this repository primarily serves as an **archival placeholder** for the original shell-script workflow while the Python rewrite is under development.

## Preferred contributions at this stage

- bug reports that identify reproducibility issues,
- documentation improvements,
- portability notes for CCP4/CCP4mg environments,
- suggestions for the Python API and workflow design.

## Before opening a pull request

Please keep in mind:

1. The legacy shell scripts are preserved for traceability.
2. Large behavioral rewrites are better directed to the Python implementation.
3. Changes should clearly distinguish between:
   - historical behavior preservation,
   - documentation improvement,
   - future-facing refactoring.

## Reporting issues

When filing an issue, please include:

- operating system,
- CCP4 and CCP4mg versions,
- the command used,
- a minimal input example,
- the observed error message,
- whether the issue affects the shell workflow, the Python placeholder, or both.
